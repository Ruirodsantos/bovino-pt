# Modelo 3D do bovino

Colocar aqui, sem alterar nomes:

- `cow.glb` — modelo GLB/glTF 2.0 com texturas PBR (de preferência com compressão Draco ou Meshopt e < 15 MB).
- `cow.json` — metadados, obrigatórios:

```json
{ "file": "cow.glb", "title": "…", "author": "…", "license": "CC BY 4.0", "license_url": "https://…", "source_url": "https://…" }
```

Sem número, licença e fonte confirmados, o modelo não se publica. Abrir `/lab/vaca-3d/` para ver o resultado (página `noindex`, fora do menu).
