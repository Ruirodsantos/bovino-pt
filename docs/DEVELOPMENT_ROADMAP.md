## 6. Risks
| Risk | Likelihood | Impact | Mitigation |
|---|---|---|---|
| Official sites block or throttle CI runners | Medium | High | Conditional requests, low cadence, polite User-Agent; fallback to running collectors on Rui's machine |
| PDF-only sources (SIMA) change layout | High | Medium | Parser fixture tests; layout change → YELLOW, never silent wrong numbers |
| Licence of a source forbids republication | Medium | High | R-002 before publishing; show derived indicators or link out instead |
| Trade-code breaks (CN 2012 change) misread as real trends | Medium | High | Explicit code mapping + break-in-series markers |
| Mirror trade data disagree (PT exports ≠ ES imports) | High | Medium | Show both, explain; never pick silently |
| Political sensitivity of "Portugal cria, Espanha compra" | Medium | High | Neutral framing, methodology published first, ChatGPT + Rui review before release |
| Agent outputs presented as facts | Medium | High | Hermes cannot write validated data; YELLOW by default for qualitative claims |
| Scope creep (other species, many pages) | Medium | Medium | Phase gates; species dimension exists but stays empty |
| Free-tier changes by providers | Low | Medium | Static output deployable to any host in minutes; no provider-specific features |
| Image rights for breed photos | High | Medium | Only own photos, explicit licences (CC with attribution), or association permission (approval needed) — placeholder illustration otherwise |
